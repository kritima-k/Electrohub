Our Story

Why ElectroHub Was Built

ElectroHub started with a simple idea — making premium technology accessible to everyone. We noticed that finding genuine, quality electronics at fair prices was always a challenge. So we built a platform that solves exactly that.

From gaming laptops and smartphones to earbuds, smartwatches and accessories — every product on ElectroHub is handpicked to ensure you get real value for your money.

We believe great technology should not be a luxury. It should be available to students, professionals, gamers and everyday users alike — and that is exactly what ElectroHub delivers.

Project Features

Project Highlights

ElectroHub combines modern frontend design with backend functionality to provide a complete e-commerce learning project.

Responsive Interface

Designed using Bootstrap to provide a clean, responsive and user-friendly experience across desktop, tablet and mobile devices.

User Authentication

New users can register and existing users can securely log in through Flask and MySQL based authentication.

Shopping Cart

Users can browse products, add items to their cart and manage selected products before checkout.

Category Navigation

Products are organized into multiple categories, making it easier for users to find gadgets quickly.

Database Integration

MySQL is used to store user registration details while Flask manages communication between the website and the database.

Full-Stack Development

The project combines HTML, CSS, Bootstrap, JavaScript, Python Flask and MySQL to demonstrate complete web application development.
